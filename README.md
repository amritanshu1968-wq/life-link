# 🩸 LIFE-LINK
## Smart Blood Donation & Emergency Blood Response Platform

LIFE-LINK is a full-stack emergency blood coordination platform designed to connect patients, hospitals, blood banks, and donors during blood requirements.

The platform helps users create blood requests, identify potentially compatible donors, manage donor responses, coordinate emergency requirements, track request status, and maintain notifications and history.

> ⚠️ LIFE-LINK is a coordination platform. It does not independently determine medical eligibility. Final donor eligibility and donation decisions must be confirmed by qualified medical professionals.

## 🎯 Problem Statement

During emergency blood requirements, finding suitable donors quickly can be difficult.

Traditional communication methods such as phone calls, messaging groups, and social media posts can make it difficult to:

- Find potentially compatible donors
- Identify nearby available donors
- Track donor responses
- Manage urgent requests
- Coordinate hospitals and donors
- Maintain request history
- Manage blood inventory
- Monitor request fulfillment

LIFE-LINK provides a centralized digital platform for managing this emergency blood coordination workflow.

# 🚀 Key Features

## 👤 Multi-Role User Management

LIFE-LINK supports multiple user roles:

- DONOR
- PATIENT / REQUESTER
- HOSPITAL
- BLOOD BANK
- ADMIN

Each role receives functionality according to its responsibilities.

---

## 🩸 Blood Request Management

Users can create and manage blood requests containing:

- Blood group
- Required units
- Location
- Priority
- Urgency
- Request details

### Supported Blood Groups

- A+
- A-
- B+
- B-
- AB+
- AB-
- O+
- O-
